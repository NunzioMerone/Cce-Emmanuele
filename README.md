# Chiesa Cristiana Evangelica Emmanuele 🙏

Sito web ufficiale della Chiesa Cristiana Evangelica Emmanuele di Napoli.

## 🌟 Caratteristiche

- **Hero dinamico** con slideshow di immagini da Google Drive
- **Gestione contenuti** tramite pannello admin
- **Sincronizzazione YouTube** automatica per predicazioni e playlist
- **Gestione eventi** con calendario e filtri
- **Ministeri** con descrizioni dettagliate
- **Gallery fotografica** interattiva
- **Form contatti** funzionale
- **Design responsive** mobile-first

## 🚀 Tecnologie

- **React 18** + TypeScript
- **Vite** per build veloce
- **TailwindCSS** per styling
- **React Router** per navigazione
- **Google Drive API** per immagini
- **YouTube Data API** per video

## 📦 Installazione

```bash
# Clona il repository
git clone https://github.com/NunzioMerone/Cce-Emmanuele.git

# Entra nella cartella
cd Cce-Emmanuele

# Installa le dipendenze
npm install

# Avvia il server di sviluppo
npm run dev
```

## 🔧 Configurazione

Crea un file `.env` nella root del progetto:

```env
VITE_YOUTUBE_API_KEY=your_youtube_api_key
VITE_GOOGLE_DRIVE_API_KEY=your_google_drive_api_key
VITE_GOOGLE_DRIVE_FOLDER_ID=your_folder_id
```
